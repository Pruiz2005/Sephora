# Sephora

El objetivo principal de este proyecto es analizar más de 285,000 opiniones de productos de Sephora para identificar patrones ocultos en las opiniones de los clientes. Mediante el uso de técnicas avanzadas de Procesamiento de Lenguaje Natural (NLP) y la extracción de metadatos clave (como tipo de piel y valoraciones), el proyecto busca descubrir tendencias de sentimiento, patrones de comportamiento y los principales indicadores de rendimiento del producto según el tipo de piel del consumidor.
